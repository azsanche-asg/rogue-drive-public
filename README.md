# Rogue Drive

An endless pixel highway game about steering pursuers into collisions and unlocking nine roads.

[Play Rogue Drive](https://roguedrive.burritoslabs.com/)

## Technology

JavaScript, browser rendering, keyboard input and touch gestures.

## Architecture

Traffic, pursuers and collision rules determine the consequences of each lane change. Swipe, tap and hold actions map to steering, boost and braking.

## Product behavior

Road progression and records stay in the browser. The standalone version provides the full play area.
